# 使用说明

1. 本地安装 ffmpeg，并且把 ffmpeg.exe 加到系统 PATH
2. 创建项目文件夹 `win_highperf_recorder`，把上面 `Cargo.toml` 和 src 下面全部文件复制进去
3. 命令行进入项目目录，执行 `cargo run --release`
4. 运行后录制屏幕 + 系统音频，输出 `out.mp4`

# 重要前置提醒

1. 需要安装 OpenH264 二进制库，`openh264` crate 需要系统加载 openh264.dll；
2. Windows COM 线程模型，程序运行期间不要锁屏 / 切换显示器，会导致 DXGI 捕获退出；
3. 编译使用 `--release`，debug 模式性能很差，会丢帧、卡顿。
